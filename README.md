###Concept

This project explores the idea that spaces can hold emotional residue.

Rather than presenting memories as timelines or feeds, MyEchos turns memory into spatial interaction.

Users can:

walk through a personal room
interact with meaningful objects
reveal handwritten memory notes
type on a real keyboard connected to a monitor
control light, curtains, and atmosphere
rearrange objects freely in 3D space

The room behaves less like an interface,
and more like a place someone once lived in.
